# Citation

If you use agent-sandbox or its results, please cite the software and name the task set and version
you used (for example `payments-v0.1`), since scores are only comparable within one task set.

```bibtex
@software{agent_sandbox_2026,
  author  = {Soni, Prarabdha},
  title   = {agent-sandbox: an OpenEnv-compatible sandbox for measuring AI agents in simulated worlds},
  year    = {2026},
  version = {0.1.0},
  url     = {https://github.com/prarabdha-soni/agent-sandbox},
  note    = {Task set payments-v0.1}
}
```

The author list will be confirmed by the repository owner before the release.
